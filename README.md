# DésiTrue Services LLC website

The public website for DésiTrue: bookkeeping, administrative and creative support. Plain HTML and CSS, hosted free on GitHub Pages.

- **Owner's guide:** [`docs/OWNER-GUIDE.html`](docs/OWNER-GUIDE.html). Read it on the live site at `/docs/OWNER-GUIDE.html` (github.com shows it as code). It covers how the site works, everyday edits, Claude Code on Windows, taking ownership of the repo, and domain move day.
- **Photo and logo prompts:** [`ASSETS.html`](ASSETS.html)
- **Preview locally:** `python3 -m http.server 4380`, then open http://localhost:4380
