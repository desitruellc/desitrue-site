DesiTrue photo & logo prompts

Ready-to-paste prompts for an AI image tool such as ChatGPT, Midjourney or Adobe Firefly. Every prompt says exactly which file it becomes, so a finished image drops straight into the site.

How to add a finished image.
  1. Download the image and crop it to the shape listed (for example 4:5).
  2. Resize it to the width listed, then shrink the file at squoosh.app (choose JPG, quality around 75). Aim for under 300 KB.
  3. Name it exactly as shown (for example hero.jpg) and put it in the assets/img folder. The site picks it up automatically, with no code to change.

Before using an AI logo everywhere: AI tools make a picture of a logo, not a proper logo file. Once she picks a favourite, have it redrawn as a vector file (SVG) by a designer (Fiverr or 99designs, often under $50) so it stays sharp on business cards and signs. AI tools also misspell words, so check that "DesiTrue" is spelled exactly right.
